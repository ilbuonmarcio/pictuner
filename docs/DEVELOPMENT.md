# First development version

Updated: 2026-10-20. This is a local development app, not a signed/notarized distribution release.

## Implemented

- Optional per-photo Date & GPS label in a toolbar popover: EXIF capture clock/offset and decimal coordinates, independent date/GPS switches, six positions, live proportional margin/text-size controls and resets. Rounded dark plate is composited after effects, aligned through crop/rotation/zoom and included in exports/histograms. Original, sampling/masks and crop drafts exclude it. Settings autosave, undo, and migrate disabled (schema 6/render 4); presets/copy/batch preserve each destination label. No guessed dates, geocoding or copied source EXIF/GPS tags.

- Hiding Workspaces moves the filmstrip below the right inspector, reclaiming its 118-point height plus divider for the photo preview. Showing Workspaces restores it below the preview; the picker scrolls to the active photo when relocated. Photo/crop controls stay beside the preview. Compact card spacing keeps all inspector controls visible at the existing minimum size, retaining slider/label sizes and histogram height.

- Four built-in export recipes: Web Page (JPEG 80%), Instagram (JPEG 100%), Full Resolution (JPEG 95%), and Lossless (16-bit PNG), all at full rendered resolution. Recipes preserve photo framing, export approval/scope and file-handling choices; manual encoding changes show Custom. PNG bit depth is independently selectable and recipe/field Reset buttons remain available. 16-bit PNG is encoded from the full rendered source without the 8-bit preview conversion.

- Straighten in the crop editor: live −15°…+15° angle slider with Reset and a drawable horizon guide, automatic edge trimming, one Apply/Cancel/undo operation for crop plus angle, and schema 5/render version 3 migration. Source-resolution geometry is shared by original, preview/detail, histogram, sampling, and export; presets/copy/batch preserve destination framing.
- Distraction-free mode in the window toolbar and View menu (⇧⌘F), with Escape to restore the editor. Hides panels/filmstrip without changing photo edits or the stored sidebar preference; retains navigation, zoom/pan, and original comparison. The normal editor returns on launch and when cropping.
- Before/after wipe in the toolbar and View menu (⌘\), with a draggable divider, Original/Edited labels, and Option-arrow/menu movement. Both sides use aligned overview/detail layers; hold-Space temporarily shows the full original. Wipe/distraction-free state never affects metadata or export.

- Show/hide 3×3 composition grid button beside the photo transforms. Visibility is remembered across launches; the grid follows the photo through zoom/pan and comparison, stays clipped to the preview, and never enters export. Crop mode retains its existing crop-relative grid.

- Removed the Natural, Mono, and Sepia preset buttons; Black & White/Sepia sliders and custom presets remain available.

- Vibrance, Clarity/Texture, Sharpening amount/radius, Noise Reduction, Glow amount/radius, shadow/highlight Color Grading with balance, and Film Grain amount/size. All use the shared renderer, existing live-preview scheduler, undo/reset/preset/copy/batch paths, and versioned autosave. Zoom crops include effect context; grain stays aligned and deterministic. Old metadata/presets decode new effects to neutral defaults.

- Opens to the current display’s full available width and height on each launch, overriding a previously saved smaller window. Respects the menu bar/Dock and retains normal window controls and resizing.

- **Reset Workspace…** in each workspace folder's context menu, with explicit confirmation before clearing all photo edits and favorite/reject/export flags across subfolders. Source files, saved presets, workspace registration/identity, and current selection are retained. Missing-file metadata entries reset too; failed/conflicting saves preserve the prior state. Workspace reset clears undo history and is unavailable during loading/export.
- Small individual Reset buttons for adjustment sliders, sampled color, histogram channels, zoom, crop aspect, and export settings. Defaults come from the existing models; image-setting resets preserve other edits and use normal undo/autosave.
- Workspaces sidebar toggle in the toolbar and View menu (⌃⌘S), with remembered visibility and more preview space when hidden.
- Correct PicTuner branding in window/alert titles, app menu, bundle name, executable, build output, and documentation; established storage paths and app identity are preserved.

- User-selected violet-aperture app icon on an off-white tile, using Goldmark Solutions’ website palette (#5924E5, #1C094D, #FBFBFD, #EEF1F7), with transparent artwork and native macOS 16–1,024-pixel representations bundled for Finder and the Dock. `scripts/build-icon.sh` regenerates the ICNS resource from the preserved source PNG.
- Wider 720-point inspector with a larger histogram (168 points tall, or 112 in shorter windows), four bordered adjustment panels with icon/title bands (Light/Effects and Color/Selective Color), and a presets/reset footer. All 36 sliders stay visible without tabs, collapsed groups, or scrolling, including when selective color is off. Minimum content size is 1340 × 900. Transform, photo flags, and copy/batch actions moved to a compact bar above the filmstrip, which presents contextual crop controls while cropping.
- Concise interface copy: no welcome slogans/sidebar assurances, quiet successful autosave, compact comparison/export controls, contextual empty-state instructions, and batch actions shown only for multi-selection.

- Registered workspace folders, recursive natural-order image enumeration, expandable subfolder navigation, and refresh/remove-reference actions.
- Non-destructive crop with corner handles, move/draw interactions, aspect presets, Apply/Cancel/Reset/Remove Crop, keyboard crop movement, and ⌘K. Clockwise/counterclockwise 90° rotation and horizontal/vertical mirror preserve existing crop selections. Source-resolution geometry is shared across preview/detail/histogram/sampling/export, with metadata schema 5 migration and undo/redo. Color presets and copied/batched edits preserve destination framing.
- JPEG/PNG loading and RAW development through `CIRAWFilter`; unsupported camera files produce an error without blocking navigation.
- Dark native interface with amber accents, a large preview, lazy thumbnail filmstrip, and source-detail zoom. Fit, actual-pixel 100%, percentage presets through 800%, zoom buttons, pinch/mouse-wheel/Option-scroll zoom, drag/two-finger pan, and double-click Fit/100% are available. Shortcuts: ⌘0, ⌘1, ⌘+, ⌘−. Actual-pixel zoom accounts for Retina backing scale.
- Left/right browsing when the preview has keyboard focus; image selection focuses the preview. Slider and text-field keyboard input stays with those controls.
- Exposure, brightness, contrast, highlights, shadows, temperature/tint offsets, saturation, hue, black and white, sepia, and adjustable vignette.
- Continuous slider previews with one in-flight render and one latest pending setting, common-mode delivery during mouse tracking, a 1,000-pixel interactive preview, and 1,800-pixel refinement after release. Cached half-float baselines avoid repeated RAW development while preserving highlight headroom; each drag remains one undo operation.
- One sampled selective-color range with tolerances, softness, selected-color saturation/exposure, outside saturation, and mask preview.
- RGB and luma histograms, with square-root-scaled counts for readability. Bins use rendered 8-bit sRGB values; luma uses 0.2126 R + 0.7152 G + 0.0722 B on those encoded values.
- Optional clipping overlay: red if any encoded channel reaches white, blue if any reaches black (white takes precedence). This is output-channel clipping, not a measurement of recoverable RAW sensor detail.
- Hold-Space and press-and-hold button comparison, with Original labeling and corresponding histogram. Accessibility activation of the button provides a one-second original preview.
- Favorites/reject flags, Command-click multi-selection, copy/paste adjustments, undoable batch application, Black & White/Sepia sliders, and named user presets.
- Persistent Include in Export flags (⇧⌘G), green filmstrip checkmarks, per-photo context actions, batch mark/unmark, and a workspace-wide marked count. Rejecting a photo unmarks it; explicitly marking it clears rejection. Existing schema 1 workspaces migrate to schema 5 with their edits preserved and all images initially unmarked.
- Per-image undo/redo with slider gesture coalescing. History is session-local and resets on image selection; batch operations can be undone before leaving that image.
- Debounced atomic JSON autosave, last-image restoration, metadata version checks, preservation of malformed/newer metadata, and external-write conflict detection.
- JPEG/PNG export with full-resolution RAW rendering, quality, optional long-edge downsizing, optional subfolder preservation, cancellation, per-file errors, and rename/skip collision behavior. Only marked, non-rejected images qualify; the default covers the whole workspace and optional scopes narrow to the current folder, selection, or favorites.

## Current limitations and deliberate first-version policies

- Export destinations must be outside all registered workspaces. Existing output replacement is not offered; rename/skip avoids replacing any existing file or link.
- Exports use sRGB and do not copy source EXIF/GPS. The export dialog states this policy.
- Camera compatibility follows the host macOS RAW decoder; only the sample listed below has been validated so far. More camera samples are needed before publishing a compatibility matrix.
- The folder tree is derived from discovered image paths, so empty folders are not shown. Filesystem changes appear after Refresh; there is no live watcher or external rename matching yet.
- Workspaces are stored as local paths in Application Support. The app currently runs without App Sandbox; security-scoped bookmarks and distribution entitlements are pending the distribution decision.
- Read-only workspaces can be browsed. Save errors are visible and editing is disabled after a persistence failure; there is no fallback metadata location. Pending edits remain in memory, with retry for a transient save failure. Failed saves block switching away or quitting to avoid discarding them.
- External metadata conflicts require reloading; automatic merging is not implemented. The save-error alert offers retry or an explicit reload-and-discard action for unsaved in-memory changes. Do not use multiple editors for the same workspace.
- Presets are presented as labeled buttons/menu items; visual preset thumbnails and additional vignette styles remain polish work.
- Custom Core Image kernels currently use the deprecated runtime Core Image Kernel Language initializer. It works on the tested Mac but should migrate to packaged Metal kernels before a distribution release; the Metal compiler toolchain component is not fully available on this Mac.
- Thumbnail images show the source rather than baked edits, with edited/favorite/reject/export-inclusion badges. The overview is capped at a 1,800-pixel long edge (1,000 while dragging sliders); visible source-detail crops refine zoomed/large Retina views, with a maximum 4,096-pixel long edge (1,000 during slider gestures). Extremely large displays may therefore need further zoom for native pixel inspection. Live frame rate depends on the image, effects, and hardware; there is no fixed FPS guarantee.
- No bokeh, spatial masks, brushes, or network services.
